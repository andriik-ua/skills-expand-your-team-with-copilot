# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Filter activities by difficulty, including activities open to all levels
- Sign up for activities

Activities can optionally have a `difficulty` field set to `Beginner`,
`Intermediate`, or `Advanced` in the activity data. Leave it out for an
activity open to all levels. The difficulty filter's **All** option shows only
those activities; **Any Difficulty** shows activities regardless of level.
